# 基于 STM32F103 + FreeRTOS 的 VL53L0X 激光测距与移动物体检测

基于 STM32F103 与 FreeRTOS 独立完成 VL53L0X 激光测距传感器的 I2C 驱动移植，封装底层读写接口，实现 **单点测距** 与 **多点扫描测距** 两种模式。软件架构基于 FreeRTOS 划分 **数据采集 / 距离计算 / 屏幕显示** 三个独立任务，通过历史距离对比实现空间内移动目标识别，长时间运行稳定。

## 功能特性

- VL53L0X 的 I2C 驱动移植（I2C1，地址 0x29），封装底层寄存器读写接口
- 单点测距 / 多点扫描测距两种模式
- 高速通信偶发数据出错的处理：调整 I2C 速率、校验时序
- FreeRTOS 三任务架构：数据采集 → 距离计算 → 屏幕显示，任务间用队列传递数据
- 移动物体检测：连续采集多组距离数据与历史值对比

## 硬件清单与接线

| 模块 | 引脚 | 说明 |
|------|------|------|
| STM32F103 | — | 主控 |
| VL53L0X（TOF 测距模块）VCC | 3.3V / GND | 供电（模块通常带板载 2.8V 稳压） |
| VL53L0X SCL | **PB6** | I2C1 时钟线 |
| VL53L0X SDA | **PB7** | I2C1 数据线 |
| VL53L0X XSHUT | 3.3V（或 GPIO 控制） | 使能，接高电平 |
| USB 转串口 | **PA9/PA10** | USART1 输出结果，115200 |

> VL53L0X 默认 7 位地址 `0x29`（HAL 8 位地址 `0x52`）。多个 VL53L0X 可通过 XSHUT 依次上电改地址实现多点扫描。

## 软件架构

```
┌──────────────────────── FreeRTOS ────────────────────────┐
│  DataAcqTask ──(rawQueue)──▶ CalcTask ──(resultQueue)──▶ DisplayTask │
│  采集 VL53L0X   距离值      滤波/移动检测   结果          UART 显示   │
└───────────────────────────────────────────────────────────┘
```

- **DataAcqTask（数据采集）**：周期读取 VL53L0X 距离，入队。
- **CalcTask（距离计算）**：滑动平均滤波，与历史值对比判断是否移动，结果入队。
- **DisplayTask（屏幕显示）**：出队并通过串口显示距离与移动标志。

## 关键技术点

1. **I2C 驱动移植**：封装单字节/多字节寄存器读写，统一超时与错误返回。
2. **高速通信纠错**：I2C 标准模式 100kHz，读写带超时重试，避免偶发数据错误。
3. **移动检测算法**：对最近 N 次距离做滑动平均，与上一次均值比较，超过阈值即判定「移动」。
4. **FreeRTOS 任务划分**：采集、计算、显示解耦，队列作为缓冲，各任务独立调度。

## 编译运行（STM32CubeIDE）

1. STM32CubeMX 新建工程：芯片 `STM32F103C8Tx`，时钟 HSE=8MHz、主频 72MHz。
2. 开启 `I2C1`（PB6/PB7，Standard Mode 100kHz）、`USART1`（PA9/PA10，115200）、`FreeRTOS`。
3. 生成工程，加入本仓库 `Inc/vl53l0x.h`、`Src/vl53l0x.c`，`main.c` 以本仓库为模板。
4. 编译烧录，串口调试助手即可看到实时距离与移动标志。

> 本驱动的初始化采用 VL53L0X 标准参考配置；如需量产级高精度，建议使用 ST 官方 X-CUBE-TOF1 库的完整校准流程。
